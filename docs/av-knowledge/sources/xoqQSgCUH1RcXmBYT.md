端到端智驾训练数据 Trick 合集（场景加权 + 数据构造 + 清洗规则）
核心思路：端到端模型天然偏向 head 常规直行车流，长尾交互场景必须做样本加权（weight 加速）+ 真实样本挖掘 + 仿真 / 生成式构造 + 针对性脏样本清洗；所有 trick 不是独立开，而是形成闭环：挖掘真实难例 → 加权提升 loss 权重 → 构造同分布变体扩充样本 → 清洗负样本 → 评测验证。
一、样本加权（weight 加速）核心策略
不是简单上采样，而是时序 clip 级 loss 权重，对决策交互段提升权重，非交互段降低权重，避免模型被普通巡航样本稀释。
路口交互权重放大：U-turn、T 型路口、红绿灯、无保护左转、跨车道博弈 clip，基础权重 ×3~×8；交互博弈关键窗口（主车与 agent 距离 < 25m、TTC<4s）权重再 ×2。
机动动作权重：换道、超车、近距离跟车，动作启动至完成的时序窗口加权；只对决策阶段加权，换道完成后恢复基础权重。
安全临界加权：TTC 小、VRU（弱势道路使用者）、异型车，靠近冲突点权重拉满；慎用极端权重，防止模型过拟合少数危险样本、出现激进行为。
负样本降权：纯巡航、无交互直路 clip，权重下调至 0.2~0.5，压缩 head 样本主导。
工程细节：不要直接复制重复样本上采样（容易过拟合），优先loss 加权；加权和数据扩增搭配使用。
二、长尾场景数据构造方案
1. U-turn / T 路口 / 红绿灯刹停远距场景
真实挖掘：地图标签匹配路口类型，提取主车掉头、T 口汇入 / 汇出；红绿灯标签 + 自车轨迹，挖掘远距离预判刹停（距离停止线 50~120m 开始平稳减速，不是临线急刹）样本，这类样本天然很少，模型容易学会临近停止线才减速。
构造变体
基于真实 clip 做场景扰动：改变信号灯时序、横向偏移邻车、增减排队车辆数量；
仿真重放：固定路口几何，批量生成不同车流密度、不同来车速度；
生成渲染：保持相机原生背景，修改信号灯状态、远处排队车辆，保留真实图像纹理。
构造目标：让模型学会提前根据信号灯 + 排队长度做长距离减速规划，而不是只看到近处停止线才刹车。
2. 效率超车：TTC 过小不超车、跟车不超
这是端到端模型最容易踩坑：一看到前车慢就强行超车，忽略对向 / 邻道来车 TTC 风险。
真实挖掘：挖掘人类老司机放弃超车样本：前车低速，但邻道来车 TTC 低于安全阈值，保持跟车、不执行超车。这类 “不做动作” 的负决策样本非常稀缺。
数据构造：
选取合法超车基础 clip，修改邻向 agent 速度，降低 TTC，构造应该放弃超车的同场景变体；
保留自车视觉输入不变，修改 agent 轨迹，生成多组 TTC 梯度样本（安全 TTC、临界 TTC、危险 TTC），学习 TTC 阈值下的决策边界；
同时保留成功超车样本，正负决策样本配比控制（成功：放弃≈1:1.2），防止模型保守不敢超车。
3. 换道加速数据构造
目标：学习换道前合理提速，不是无脑猛加速，也不是低速硬切。
真实挖掘：筛选有效换道：目标车道后方车辆 TTC 充足，主车小幅提速，平稳并入；剔除被迫紧急换道、cut-in 类危险样本。
构造：
轨迹扰动：微调目标车道后车速度，生成不同间隙下的加速 / 匀速换道；
时序拆解：保留换道前观察、加速、横向切入、回正完整时序；
负例构造：间隙不足时，构造放弃换道，保持原车道样本。
4. 异型车数据构造（叉车、工程车、超长挂车、农用机械、异形静态障碍物）
感知 + 规划双重长尾，真实路采极少。
真实挖掘：从车队日志挖掘少量真实异型车 clip，作为基底；
Inpainting / 神经渲染：在真实相机画面中替换普通车辆为异型车，保持光照、阴影、相机畸变、3D 位姿对齐；同步修改 BEV / 目标轨迹标签；
仿真批量生成：不同距离、遮挡、角度，异型车静止 / 低速横穿；
注意坑：只贴图片不修正 3D 框，会造成感知 - 规划分布错位，训练出伪样本。
5. 无保护左转交互构造（重点难点）
核心是博弈交互：对向直行车辆速度、距离、意图预判，主车试探 / 等待 / 抓住间隙左转。
真实挖掘：挖掘对向车流里的间隙博弈样本，包含：等待大车流、抓住短暂间隙、对向车加速抢行而放弃左转；
构造思路：
固定路口几何，修改对向直行 agent 的速度、起始位置，生成多组间隙大小；
生成交互博弈：对向车减速礼让 / 加速抢行两种行为；
时序窗口拉长：包含左转前观察、等待、进入路口、驶出完整过程，不能只取转弯一瞬间；
训练目标：模型学习读对向车意图，而不是只靠距离硬规则。
6. 跨车道博弈构造（多车抢道、汇入、多车互相挤占路权）
典型场景：多车并行、匝道汇入、拥堵路口多车抢空间。
基底：真实多车交互回放场景；
构造：微调周边所有 agent 轨迹，制造多组博弈强度梯度：温和让行、互相试探、近距离抢道；
标签要求：保持所有 agent 时序轨迹一致性，保证多智能体交互物理合理，不能出现穿透、瞬移。
三、专项数据清洗规则（过滤脏样本）
1. 刹停排队清洗：短队，速度超阈值脏样本
问题：短排队（前车数量≤2 辆），人类 / 回放轨迹出现不合理高速冲到近处急刹；这类样本会污染模型，学会临近才猛刹。
清洗规则：
场景标签：红绿灯路口，排队长度 N≤2；
规则：距离停止线大于阈值（如 > 60m），自车速度 > 阈值（如 > 40km/h），后续短时间内大幅减速度；
处理：直接过滤该 clip，或者降权重；保留长队列下的远距平稳减速样本。
2. 高架超车数据倍增 + 清洗
高架场景：高速、车速高，超车决策容错窗口小。
倍增：基于真实高架超车 clip，做 agent 速度扰动，生成不同后车 / 对向车（如果是双向高架）间隙变体；同一场景多难度梯度扩充；
清洗项：
TTC 低于安全阈值还执行超车的危险回放轨迹，剔除；
邻道车辆横向距离过小的硬切超车；
遮挡严重、感知漏检导致的虚假超车样本。
3. 不绕行 VRU 样本清洗
脏样本：前方行人 / 非机动车，回放轨迹没有减速、绕行，直接逼近；属于不良示范，端到端模型很容易学到不避让 VRU。
清洗策略：
规则挖掘：VRU 在自车前方路径，距离 < 20m，自车无减速 / 绕行动作；
分级处理：
严重危险样本：直接丢弃；
临界样本：保留但设置极低权重，不做主力训练；
配套：大量补充减速、停车、绕行 VRU的正样本，平衡分布。
四、工程落地避坑
仿真 / 生成样本一定要做 sim2real 校验：纯仿真图像纹理、噪声、物体光影和真实相机差异大，直接灌训练会造成上线分布偏移；优先用真实场景基底做渲染编辑，而不是从零生成画面。
加权不要全局静态固定：训练中动态统计场景分布，动态调整权重，防止某类场景过拟合。
样本时序完整性：端到端是时序模型，不要只切关键单帧；clip 必须保留足够历史上下文 + 未来轨迹标签。
正负决策样本平衡：不仅要学 “该做什么动作”，还要学 “什么时候不做动作”（不超车、不换道、原地等待），这类负决策样本往往是长尾短板。
五、流水线顺序
日志挖掘 → 场景标签打标（Uturn/T/ 红绿灯 / VRU / 异型车） → 脏样本清洗（刹停脏样本、VRU 不绕行、危险超车） → 真实样本加权 → 仿真 / 生成式构造长尾交互变体 → 混合真实 + 合成数据集 → 训练 + 闭环评测，失败案例回流挖掘扩充。

临界样本：保留但设置极低权重，不做主力训练；
配套：大量补充减速、停车、绕行 VRU的正样本，平衡分布。
四、工程落地避坑
仿真 / 生成样本一定要做 sim2real 校验：纯仿真图像纹理、噪声、物体光影和真实相机差异大，直接灌训练会造成上线分布偏移；优先用真实场景基底做渲染编辑，而不是从零生成画面。
加权不要全局静态固定：训练中动态统计场景分布，动态调整权重，防止某类场景过拟合。
样本时序完整性：端到端是时序模型，不要只切关键单帧；clip 必须保留足够历史上下文 + 未来轨迹标签。
正负决策样本平衡：不仅要学 “该做什么动作”，还要学 “什么时候不做动作”（不超车、不换道、原地等待），这类负决策样本往往是长尾短板。
五、流水线顺序
日志挖掘 → 场景标签打标（Uturn/T/ 红绿灯 / VRU / 异型车） → 脏样本清洗（刹停脏样本、VRU 不绕行、危险超车） → 真实样本加权 → 仿真 / 生成式构造长尾交互变体 → 混合真实 + 合成数据集 → 训练 + 闭环评测，失败案例回流挖掘扩充。
这个场景体系涉及大量时序规则、样本配比和仿真变体构建，工作任务模式可以帮你整理成可直接落地的数据挖掘 SQL 规则、清洗过滤代码片段和训练权重配置表，要不要用它处理？
