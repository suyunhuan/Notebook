## 3. 「一条量产 VLA」的端到端故事线

手写给出更清晰的产品叙事，可用豆包笔记补原理：

1. **传感器 → Token**（手写 26/30）  
   环视 ConvNet + 前视 DINOv2 + Lidar UNet + Navi(SD+TBT) → ~1000 token。  
   *对照*：豆包 14（PV→BEV）、13（深度）。

2. **FM 骨干**（手写 28/30）  
   Max/Ultra/Ultimate 缩放；Self-Attn×N；可选 MLLM。  
   *对照*：豆包 01（分阶段解冻）、16（Qwen3-VL 插件式）。

3. **结构化辅助头**（手写 20/21）  
   NaviNN 场、TrafficNN 通行概率、GOD/SparseDet/PV Seg/Depth。  
   *对照*：豆包 02（BEV+PNC 栈）。

4. **推理条件化动作**（手写 22/25/27）  
   VLM 中间 KV → CrossAttn → DiT waypoints；或 Latent Reasoning rollout；CoC/STL 约束。  
   *对照*：豆包 09/08/10/11。

5. **数据与对齐闭环**（手写 23/24/27）  
   P1 多样性防固化；Scene Graph 打标；慢快 Rollout→DPO；OPD/MOPD；Toggle 控推理长度。  
   *对照*：豆包 07/12/03。

6. **训推工程**（手写 29）  
   &lt;7B Swift LoRA；更大 Megatron TP/PP/DP…  
   *对照*：豆包 15/04/06。
