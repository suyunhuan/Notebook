## 一句话摘要

端到端规控以「清洗可行真值 → 重采样 → 多目标 SFT → 离线 DPO 偏好对齐 →（可选）仿真 GRPO/PPO」为骨架，负样本必须同场景配对且弱负为主。

## 核心关键词

`真值改造` · `样本配比` · `多目标 Loss` · `动态权重` · `Reward` · `DPO` · `GRPO` · `弱负/强负` · `安全兜底层`

## 知识脉络（方法论框架）

> 原文极长且偏工程经验；此处提炼可复用框架，比例数字均为**经验区间**，需按车型/数据复验。

### 0. 总链路

```
原始轨迹 → 真值清洗/修正 → 分层重采样
  → SFT（多目标 Loss + 动态权重）
  → DPO 离线偏好微调（同场景 chosen/rejected）
  → [可选] 仿真 GRPO/PPO
  → 安全校验层（规则/优化器兜底）
```

智驾约束异于 LLM：硬安全、动力学可达、交通规则、时序连续；RL 几乎只在仿真探索。

---

### 1. 真值改造（SFT 底座）

| 手段 | 目的 |
|------|------|
| 平滑 + 动力学可行性校验 | 避免学物理不可达轨迹 |
| 多候选/偏好等级 | 同一场景多种合法方案，为 DPO 铺路 |
| 专家规划器替换人类失误 | 危险场景不当正样本 |
| 时戳对齐 | 传感器与驾驶动作同步 |
| 负样本真值 | 供偏好/对比学习，不作 SFT 正监督 |

原则：SFT 优先「安全可行」；坏人类行为进 rejected，不进正真值。

---

### 2. 采样配比（前置）vs Loss 权重（后置）

- 长尾：分层 batch（常规 / 交互 / 难例），Hard Example Mining（离线误差大 / 在线违规）。
- 域配比：高速/城区/天气；仿真补长尾，实车保域差。
- **勿过度放大危险样本** → 过度保守、无故急刹。
- 采样与动态 weight 分工：前者控分布，后者控单样本/分项强度。

---

### 3. Loss 与动态权重

\[
L = w_{traj}L_{traj} + w_{vel}L_{vel} + w_{jerk}L_{jerk} + w_{safety}L_{safety} + w_{rule}L_{rule}
\]

- 轨迹：MSE/L1/Huber；平滑为**输出自身正则**；安全/规则为软约束惩罚。
- 动态权重：场景感知切换；难例放大；退火（先拟合后安全/舒适）。
- 局限：多目标冲突时调权重难收敛 → 偏好学习把「调权」转为「定义好坏对」。

---

### 4. Reward（RL/GRPO 基础）

- 项：progress / comfort / safety / rule / efficiency；稠密易 hack，稀疏难学，常混合。
- 技巧：量纲归一、hinge（阈值内不罚）、分场景权重表。
- 实车不做在线危险探索。

---

### 5. DPO（离线偏好对齐）

**单元**：固定场景 \(s\)，成对 \((\tau_{chosen},\tau_{rejected})\)——**禁止跨场景配对**。

**负样本来源（成本↑）**

1. 旧模型/同模型多样本差轨迹  
2. 改参专家规划器（可控违规类型）  
3. 同司机片段好坏拆分（慎用严重事故）  
4. 对优质轨迹可控扰动（勿造物理不可达）  
5. 仿真 rollout + 规则打分  
6. 少量人工黄金对（校准自动偏好）

**弱负 vs 强负**

- 弱负（可行但更差）：学习主力。  
- 强负（碰撞/硬压线）：少量建底线；过多 → 龟速急刹。

**与 SFT 关系（经验框架）**

| 维度 | 经验方向 |
|------|----------|
| 阶段 | 串行：SFT 完成后再低 LR DPO；少做同 batch 混训 |
| 场景分布 | DPO 大体对齐 SFT，难例略升（如常规↓、难例↑） |
| 弱/强负 | 弱负为主（如 ~80%），强负 ≤~20% |
| 来源混合 | 旧模型错例 + 规划器可控负 + 仿真长尾 + 少量人工 |
| \(\beta\) | 连续轨迹 DPO 常小于 LLM 文本设定；强负多时需更谨慎调 \(\beta\) |

连续轨迹常用 KL 约束变体（IPO / KL-DPO 等）防崩。

---

### 6. GRPO vs DPO vs PPO

| 方法 | 数据 | 在线 rollout | 特点 |
|------|------|--------------|------|
| DPO | 离线偏好对 | 否 | 稳、改风格与安全偏好 |
| GRPO | 同场景组内多样本 | 是（多为仿真） | 组内相对分，免独立 RM |
| PPO | 在线交互 | 是 | 绝对 reward，易不稳/hack |

串联而非互斥：SFT → DPO →（可选）仿真 GRPO。

---

### 7. 失败模式速查

- 全强负 → 过度保守  
- 跨场景对 → DPO 失效  
- DPO 分布远离 SFT → 基础驾驶退化  
- 仅人造扰动负样本 → 仿真涨、实车不涨  
- 无安全兜底 → 长尾硬约束仍不可靠  

## 知识点校验

- **Correct**：同场景配对、SFT 打底再 DPO、弱负为主、仿真 RL + 实车安全层——方法论逻辑自洽。
- **Caution**：文中 70/20/10、弱负 80%、来源 50/30/15/5、\(\beta\in[0.1,1]\) 等均为**口述工程经验**，非公开 benchmark 最优；直接照搬有风险。
- **Caution**：将「连续动作 DPO / IPO」与 LLM token-DPO 公式直接类比时，似然定义、参考策略、KL 实现因团队而异，需对照具体实现，勿当作唯一标准式。
- **Expand**：偏好对自动去歧义过滤；曲率限速/启停/回正等专项真值改造与 EMA 舒适代价的可复现实验设计；闭环仿真 A/B 防 reward hack 的扫参协议。
