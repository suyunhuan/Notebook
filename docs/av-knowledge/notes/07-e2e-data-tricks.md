## 一句话摘要

端到端模型偏置 head 巡航分布，需用「clip 级加权 + 真实难例挖掘 + 同分布构造变体 + 脏样本清洗」闭环，特别补齐「该做的动作」与「故意不做的负决策」。

## 核心关键词

样本加权；长尾；TTC；U-turn / T 路口；无保护左转；异型车；VRU；负决策；Sim2Real；高架超车

## 知识脉络

### 1. 加权原则（优先 loss 权重，慎盲目上采样）

- 交互 clip 基础权重可 ×3~×8；冲突窗口（如距离 <25m 且 TTC<4s）再 ×2。
- 机动动作只在「决策段」加权，完成后恢复。
- 巡航 head 样本可降权至 0.2~0.5。
- 极端安全权重慎用，防过拟合少数危险示范导致激进。

### 2. 长尾构造（真实基底 + 扰动 / 仿真 / 渲染）

| 场景 | 目标 | 要点 |
|------|------|------|
| U-turn / T / 远距刹停 | 学会 50–120m 级预判减速 | 改灯态、排队、车流密度；避免只学临线急刹 |
| 效率超车 | 学「TTC 不够则不超」 | 负决策稀缺；TTC 梯度样本；成功:放弃≈1:1.2 防过度保守 |
| 换道加速 | 合理提速并入 | 保留观察→加速→切入→回正；间隙不足则放弃换道负例 |
| 异型车 | 感知+规划双长尾 | 贴图必须同步改 3D/BEV/轨迹，否则伪样本 |
| 无保护左转 | 读对向意图与间隙 | 拉长观察–等待–通过时序；礼让/抢行两种对手 |
| 跨车道博弈 | 多车路权 | 保持多智能体物理一致，禁穿透瞬移 |

### 3. 清洗规则（坏示范必滤）

- **短队高速冲停**：排队 ≤2、距停止线仍远却高速后急刹 → 滤或降权。
- **高架危险超车**：TTC 过低仍超、硬切、感知漏检伪超车 → 剔除；安全变体可倍增。
- **不绕行 VRU**：路径内近距 VRU 无减速/绕行 → 严重丢弃，临界极低权，并补正样本。

### 4. 流水线与避坑

```
日志挖掘 → 场景打标 → 脏样本清洗 → 真实加权 → 合成变体 → 混合训练 → 闭环评测回流
```

- 优先真实场景编辑，纯仿真需 sim2real 校验。
- 权重宜动态按分布调整，避免某类过拟合。
- Clip 保留足够历史与未来标签，忌只切关键单帧。

## 知识点校验

1. **Caution**：文中具体阈值（25m、TTC 4s、权重 ×3~×8、1:1.2 等）是经验模板，需按车速域、传感器与法规重新标定，不能直接当全局超参。
2. **Caution**：「搜索参考 24 篇资料」的合成叙述可能混入通用最佳实践，与本车队真实分布未必一致，应用前用 held-out 闭环指标验证。
3. **Expand**：生成式/inpainting 异型车在检测 mAP 上升但规划变差时，应查 3D 标签与动力学是否同步——这是常见隐形失败模式。
4. **Correct**：端到端长尾依赖加权与负决策样本、VRU 坏示范必须清洗，是业界共识方向。
