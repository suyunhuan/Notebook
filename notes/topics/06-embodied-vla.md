# 主题：具身智能与 VLA

关联页：01, 14, 15（兼 13 流式、21 CoT）

---

## 1. 数据到真机链路

```
human data → 物理交互 → 复杂任务 → Foundation Model → 真机
```

硬件侧：2/3/5 指灵巧手；**视、触、关节**多模态；RL 低层控制。  
关键能力 ①：**力觉柔顺**与精细操作（阻抗/导纳思想，避免刚性碰撞）。

---

## 2. 认知架构

```
        ┌─ VLM：长程、显式记忆
Memory ─┤
        └─ WM：物理、动作
              ↓
     语义接口 + 具身推理链
              ↓
         Critic Model ──回写 Mem──►
```

与车端差异：机器人更强调接触力与失败恢复；车端更强调 Hz 与规则约束。共享点是 **VLM 管语义、WM 管动力学**。

---

## 3. Memory Bank Event

- **Omni Stream**：4D，兼容 2D；ViT 与图像 align（耗资源）。  
- 数百帧 streaming；**memory 衰减但不会消失**（重要事件保留）。  
- depth 一致；1280 输入；低→高分辨率两阶段。  
- 几何 + 语义自监督（dense depth）；开放问题：**depth 是否足够？**（通常还需语义、触觉、接触事件）。  

---

## 4. VLA 设计要点（页 01）

- Causal 对齐交互流；离散动作 + RL；CFG 离散/连续。  
- MoT + Memory；快慢系统；3D ViT。  
- 统一表征空间上的高效部署。  
- 评测：数据、仿真、真机/路测。  

Video Thinking 提供「想象未来再行动」的 WM 接口，可迁移到机械臂视频策略。

---

## 5. 迁移到车端的注意点

| 具身 | 车端对应 |
|------|----------|
| 力觉柔顺 | 舒适性与避撞纵向 |
| 触觉 | 碰撞/加速度 IMU 代理，非直接触觉 |
| Memory Bank | KV Cache + Sparse BEV 长时序 |
| Critic | Reward Model / STL 违例 |
| 真机 | 路测 + 闭环数据 |

---

## 6. 检查清单

- [ ] 是否同时采集视觉与力/关节（避免纯视觉幻觉）  
- [ ] Memory 是否有事件触发写入（而非均匀衰减）  
- [ ] 仿真域随机化是否覆盖摩擦与接触  
- [ ] VLA 离散 token 与连续控制如何切分快慢环
